# Mobile Phone Store

An Android application developed for the **Mobile Device Technology and Applications** course at the Islamic University of Madinah (First Semester 2024–2025).

## Project overview
The application simulates a mobile phone storefront with two user roles:
- **Customers:** browse available products, add quantities to a cart, and view a checkout bill.
- **Admins:** manage users and products, including adding, updating, and deleting records.

## Technologies
- Java
- Android SDK / Android Studio
- XML layouts and Android resources
- SQLite

## Main features
- User registration and login
- Separate customer and admin screens
- Product inventory management
- User management
- Cart and checkout summary
- Local SQLite database
